# Трипмастер Р3К

Трипмастер для ралли на регулярность в браузере телефона: GPS-дистанция в км легенды,
отклонение от идеального времени в секундах, калибровка, синхронизация по точкам легенды.
Работает офлайн после первого открытия.

## Установка на Android (Chrome)

1. Открыть ссылку GitHub Pages в Chrome, разрешить геолокацию.
2. Меню ⋮ → «Добавить на главный экран» / «Установить приложение».
3. Один раз открыть установленное приложение при наличии сети — дальше работает без неё.

## График

Вкладка «График», одна строка на смену режима: `км скорость [чч:мм:сс]`.

```
0.00 47 10:05:00   # старт участка
3.20 36            # с км 3.20 средняя 36
12.40 0            # стоянка
12.40 45 10:22:00  # рестарт после КВ
```

## Перед гонкой

- Поправка часов: официальное время минус время телефона, в секундах.
- Калибровка на мерном участке: «Я в точке А» → проехать → «Я в точке Б».
- Экран не гасить: при выключенном экране браузер перестаёт получать GPS.
